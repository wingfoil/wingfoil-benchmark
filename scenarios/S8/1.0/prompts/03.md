Some screens pass whatever the user typed straight to the list, and odd tasks show up. Please reject
invalid input with a clear error that says what is wrong:

- a title that is empty, or only spaces;
- a title longer than 120 characters;
- a priority other than `low`, `normal` and `high`;
- a tag that is empty or contains a space.

This applies when a task is added, renamed or tagged. When input is rejected, nothing in the list
changes.
