# tidy-tasks

The task list behind Tidy Tasks, a small to-do app for households and small teams. People add tasks with
a title, a priority and a few tags, tick them off when they are done, and look at what is left, most
urgent first. This package holds the list itself, in TypeScript; the app's screens use its public API
from `src/index.ts`.

Run its tests with `npm test`.
