The app needs a stable way to refer to a task, one that still works after the task is renamed. Please
give each task a unique identifier.

The task that `add` returns has an `id`, a string that no other task of the list has. The list gets a
`get(id)` method that returns the task with that id, as a result like the list's other methods. The
methods that take a title (`find`, `complete`, `reopen`, `rename`, `tag`, `untag` and `remove`) accept a
task's id as well.
