We are starting a spring campaign and customers will get discount codes in our newsletter. Please let an order take a
code:

- `SPRING10` takes 10 % off the order's items, rounded to the nearest cent (a half cent rounds up);
- `WELCOME5` takes 5.00 € off the order's items, only on an order whose items come to 30.00 € or more.

An order takes one code at most; a second code replaces the first. An unknown code, or `WELCOME5` on a smaller order,
is refused with an error that says why, and the order is left as it was. The discount never touches shipping, and
whether an order ships free is still decided on its items before any discount.

The order book should offer `applyCode(orderNumber, code)`, and an order's totals should show the discount as
`discountCents` (0 without a code), with `totalCents` as items minus discount plus shipping.

We would like customers to have this in time for the newsletter.
