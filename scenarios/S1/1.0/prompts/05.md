Our clients now want to send only what changed between two versions of a JSON document, instead of the
whole new version. Please add a way to produce such a change as a JSON Patch (RFC 6902).

Export a function `createPatch(from, to)` from `src/index.ts`. It returns a JSON Patch that turns `from`
into `to` when applied, and must not mutate either input. The patch should describe what changed, and
nothing more: when two versions differ in one small place, sending the whole document again is not
acceptable.
