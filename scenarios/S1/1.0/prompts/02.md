Next, our services need to change JSON documents with standard patches. Please implement JSON Patch, as
specified in RFC 6902, with its six operations: add, remove, replace, move, copy and test.

Export a function `applyPatch(document, patch)` from `src/index.ts`. It applies a JSON Patch (an array
of operations) to a JSON document and returns the resulting document as a new value: it must not
mutate its input. It throws an error when the patch is invalid, or when one of its operations fails.
