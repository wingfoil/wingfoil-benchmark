Our services need a standard way to refer to a value inside a JSON document. Please implement JSON
Pointer, as specified in RFC 6901.

Export a function `resolvePointer(document, pointer)` from `src/index.ts`. Given a JSON document and a
JSON Pointer string, it returns the value the pointer refers to. It throws an error when the pointer is
not a valid JSON Pointer, or when it does not resolve to a value of the document.

This is the first of a few features that build on each other: the next ones will use it.
