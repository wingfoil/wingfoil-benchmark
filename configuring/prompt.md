# Configure this project's development tool

This repository is a project an AI coding agent will work on: its code, its README and its tests, with a development
tool already installed and initialized for it. The tool came with its own files and documentation. Nobody has
configured it for this project yet.

Your task is to configure the tool, and the coding agent's integration with it, for this project, so that an agent
given the project's future requests is guided well by it. You are not asked to change the project.

1. Learn the project: read the README and the code. Find its language and runtime, its structure, its conventions,
   how it is built and tested, and any rule its README states.
2. Learn the tool: read its documentation and the files its setup installed, to find where and how it is configured
   for a project (its rules or principles, its project context, its settings, the agent's instructions or skills it
   installed).
3. Write the configuration: write or extend those files, in the places the tool's documentation names, with what you
   learned about this project. Keep what is already there, and extend it; where the project already has rules for the
   tool, keep each of them.

Change configuration only:

- Do not add, change or delete the project's code, tests, README, package files or any other project file.
- Do not delete any file, and do not create symbolic links.
- Do not record any work in the tool: no task, change, specification, plan or other record.
- Do not change the project's team: its members, their roles or the roles' definitions.
- Do not write an instructions file at the project's root (such as `CLAUDE.md` or `AGENTS.md`).
- Do not implement or fix anything in the project.

When you are done, reply with a short list of the files you wrote, each with one line on why.
