# Spending ledger — release v0.2

Every run of the real agent during release v0.2, one line each, in date order
([dl-006](../memory/decision-log/dl-006-real-agent-runs-during-delivery-are-declared-by-the-workflow.md)), on the
model of [v0.1-ledger.md](v0.1-ledger.md). A spike's line is written when it spends; a wave check's, when
`kanban-delivery`'s `real-agent-check` records it; calibration's dry runs, validation's runs and the campaign add
theirs in their phases (`release-cycle` 3).

Costs are the API-equivalent the agent reports (`total_cost_usd`), on the maintainer's subscription: nothing is
billed per token (sequencer decision 1). EUR at the rate the run's campaign declares, or, for a spike, not converted.
**None of the delivery runs is a dry run**: calibration measures its own.
