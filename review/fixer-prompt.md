# Fix the review's findings

An independent review of this project's latest change reported the findings listed above this text. Fix each of them,
in the file and at the place it names, so that the problem it describes no longer happens.

Fix exactly these findings, and nothing else: no other change, no refactoring, no new feature, no change to files the
findings do not concern unless a fix needs it. When you believe a finding is wrong, leave the code as it is for it and
say why in your answer. Work as you work on any request in this project, following its rules and your usual way of
recording your work.

When you are done, commit your changes with a message that names the findings you fixed.
